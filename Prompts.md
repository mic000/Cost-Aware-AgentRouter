This file records how generative AI (Claude) was used during Project 13, as
required by the course. All AI-generated code and text were reviewed and edited

pipeline (`router_lib.py`, `06_experiments.py`), not from the AI; the AI was used
to help write and check the code, not to produce the numbers.

## Summary

Claude was used as a collaborator in three main areas:

1. **Routing-scheme design.** We designed and compared several routing schemes
   with Claude for choosing among the five coding agents: a success-only argmax
   router, a cost-aware (lambda-penalized) router, an instance-level router driven
   by the per-task model score, and the cell-based cost-gap router that became the
   headline policy. Claude helped reason about the trade-offs of each scheme and
   about how to value them off-policy when only one agent is observed per task.

2. **Dataset cleaning and construction.** We used Claude to help write and debug
   the pipeline that turns the raw AIDev dump into the balanced router corpus:
   filtering to the five agents, labelling PRs from `state` / `merged_at`, joining
   repository metadata, deriving `task_type` and the cleaned title, and
   down-sampling to a per-agent floor.

3. **Report drafting.** Claude helped draft the first version of the report and
   later helped tighten the prose, cross-check the numbers against the experiment
   outputs, and catch inconsistencies.
